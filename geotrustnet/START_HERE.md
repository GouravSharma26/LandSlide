# Start Here — Antigravity Starter Pack

1. Copy the contents of this pack into the root of your existing LandSlide repository, preserving any existing `AGENTS.md` and `README.md` by merging rather than overwriting.
2. Start Antigravity with `docs/geotrustnet/ANTIGRAVITY_EXECUTION_PROMPT.md`.
3. Require Phase 0 audit only. Review the audit before authorizing implementation.
4. Proceed phase by phase using `AGENTS.md` and `docs/geotrustnet/IMPLEMENTATION_ROADMAP.md`.

Key files:
- `AGENTS.md` — repository-wide agent rules.
- `README_GeoTrustNet_Plan.md` — unified product vision.
- `docs/geotrustnet/RESEARCH_SPECIFICATION.md` — research question, tasks, architecture.
- `docs/geotrustnet/DATA_AND_PROVENANCE.md` — dataset and preprocessing contracts.
- `docs/geotrustnet/MODEL_DESIGN.md` — model components and interfaces.
- `docs/geotrustnet/EXPERIMENT_PLAN.md` — baselines, metrics, ablations.
- `docs/geotrustnet/IMPLEMENTATION_ROADMAP.md` — phased build plan.
- `docs/geotrustnet/TESTING_AND_ACCEPTANCE.md` — quality gates.
- `docs/geotrustnet/LITERATURE_REVIEW.md` — source register and review framework.
- `docs/geotrustnet/ANTIGRAVITY_EXECUTION_PROMPT.md` — first prompt to run.
